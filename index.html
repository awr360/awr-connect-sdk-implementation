Overview

The AWR Connect Client JS SDK (awr-client-js-sdk) lets you connect your own UI to the AWR Connect chat platform via a Custom Channel. You use the channel’s connection key (channelId) and secret to send messages over REST and receive agent replies in real time over Socket.IO.

  • Real-time: Pass sessionId in config and call connect(); the SDK opens Socket.IO and joins a session room. Agent messages arrive via message; status via message_status; media finalize via message_media_ready.
  • REST: sendMessage(), sendMessageStatus(), and getConversation(sessionId, options); call connect() first.
  • Media: Use uploadMedia(file, { sessionId, mediaType }) (S3 upload-intents), then sendMessage(caption, { sessionId, messageType: 'media', mediaUrl, mediaType }). History/socket payloads may include time-limited mediaUrl / thumbnail.
  • Use a stable sessionId per visitor (must not contain :). options.sessionId is required on every sendMessage(), uploadMedia(), and sendMessageStatus().
  • Requires awr-client-js-sdk@0.2.0 or later. Obtain the connection key and secret when creating the Custom Channel in the webapp; the secret is shown only once.

Installation

From your project root:

pnpm add awr-client-js-sdk

In the browser, load the UMD bundle from unpkg or a local build of awr-connect-custom-channel-js-sdk: 

<script src="https://unpkg.com/awr-client-js-sdk@0.2.0/dist/index.umd.js"></script>

Quick start

Config uses baseUrl, channelId, and secret. For real-time receive, add sessionId (and optional visitorName). Register listeners before connect(). Send only after connection_ready fires (no payload). getConversation(sessionId, options) requires the client to be connected.

import { AwrConnectClient } from "awr-client-js-sdk";

const sessionId = "user-session-123";
const client = new AwrConnectClient({
  baseUrl: "https://your-api.example.com",
  channelId: "your-connection-key",
  secret: "your-channel-secret",
  sessionId,
  visitorName: "Alice",
});

client.on("connection_ready", () => {
  // Only then send or load history
});
client.on("connection_error", (err) => console.error(err));
client.on("message", (msg) => console.log("Agent:", msg.textMessage, msg.mediaUrl));
client.on("message_status", (p) => console.log("Status:", p.socialMessageId, p.status));
client.on("message_media_ready", (msg) => console.log("Media ready:", msg._id));
client.on("error", (err) => console.error(err));

client.connect();

// After connection_ready:
const sent = await client.sendMessage("Hello!", { sessionId, visitorName: "Alice" });
console.log(sent.socialMessageId);
const { messages, pagination } = await client.getConversation(sessionId, { page: 1, limit: 20 });
client.disconnect();

Media upload & display

Upload flow: Call uploadMedia(file, { sessionId, mediaType, onProgress? }) after connect() / connection_ready. The SDK creates an upload intent, PUTs to S3 (single or multipart), then completes/polls until ready. Returns { mediaUrl, mediaType, thumbnail? }. Then send: sendMessage(caption, { sessionId, messageType: 'media', mediaUrl, mediaType }). Upload mediaType: 'image', 'audio', 'document'.

Size limits: Image 10 MB, audio 16 MB, document 25 MB. Allowed types: common image/audio MIME types and PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, TXT.

URLs: getConversation() and socket events may return time-limited (pre-signed) mediaUrl / thumbnail values usable in the browser. Prefer helpers getMessageDisplayUrl / getMessageFullUrl. Listen for message_media_ready when finalize is deferred.

Link lifetime: Treat media URLs as expiring (typically on the order of 1–2 hours depending on path). Refresh from history or wait for message_media_ready if a link stops working.

Display: This example renders images inline (<img>), audio with <audio controls>, and documents as download links. Use messageType and mediaType to choose the right UI.

API reference

constructor(config?: AwrConnectConfig)
Create a client. Pass baseUrl, channelId, secret; optionally sessionId, visitorName, requestId.
setConfig(config: AwrConnectConfig): void
Set or update configuration.
connect(config?: AwrConnectConfig): void
Validate config and mark client connected. If sessionId is set, opens Socket.IO to /custom and joins the session room; connection_ready fires when the server acknowledges (no payload). 10s join timeout. Throws if baseUrl, channelId, or secret is missing.
disconnect(): void
Close Socket.IO (if open) and mark client disconnected.
isConnected(): boolean
Return whether the client is in a connected state.
isRealtimeReady(): boolean
When sessionId is set, true only after custom:join succeeds. sendMessage, uploadMedia, and sendMessageStatus wait for this automatically.
uploadMedia(file: File | Blob, options: UploadMediaOptions): Promise<UploadMediaResponse>
Upload via S3 upload-intents (create → PUT → complete/poll). Options: sessionId, mediaType ('image' | 'audio' | 'document'), visitorName?, requestId?, onProgress?(percent). Returns { mediaUrl, mediaType, thumbnail?, metadata? }. Then call sendMessage(caption, { sessionId, messageType: 'media', mediaUrl, mediaType }). Lower-level: createUploadIntent, uploadToS3, completeUploadIntent.
sendMessage(textOrContent: string, options: SendMessageOptions): Promise<{ success: boolean; message?: string; socialMessageId: string }>
Send a text or media message. options.sessionId is required (must not contain :). Options: visitorName?, messageType? ('TEXT' | 'media'), mediaUrl? (required when messageType is 'media'), mediaType? ('audio' | 'image' | 'video' | 'document'), socialMessageId? (auto-generated when omitted). Always returns socialMessageId. Emits error on API failure.
sendMessageStatus(options: SendMessageStatusOptions): Promise<{ success: boolean; message?: string }>
Report delivery/read for an agent message. Options: sessionId, socialMessageId, messageType ('READ_UPDATE' | 'DELIVERY_UPDATE' | 'STATUS_UPDATE'), status ('READ' | 'DELIVERED' | 'SENT' | 'FAILED'), visitorName?.
markMessagesRead(sessionId: string, socialMessageIds: string[], visitorName?: string): Promise<{ success: boolean; failed: string[] }>
Sends READ_UPDATE for each id. Returns which ids failed.
getMessageStatus(sessionId: string, socialMessageId: string): MessageDeliveryStatus | undefined
Last cached status from local send, history, or message_status events.
getChannelInfo(): Promise<ChannelInfoResponse>
GET channel details (secret not included). Requires client connected.
getConversation(sessionId: string, options?: GetConversationOptions): Promise<GetConversationResponse>
GET paginated messages. Call connect() first. Options: page? (default 1), limit? (default 20, max 100). On 404 returns empty messages (no throw).
loadAllConversationMessages(sessionId: string, options?: { limit?: number; maxPages?: number }): Promise<SimplifiedMessage[]>
Fetches all pages (up to maxPages, default 100) and returns messages sorted oldest → newest.

Types

interface AwrConnectConfig {
  baseUrl: string;
  channelId: string;
  secret: string;
  sessionId?: string;   // required for real-time receive; must not contain ":"
  visitorName?: string;
  requestId?: string;   // sent as X-Request-Id
}

type MessageDeliveryStatus = 'sent' | 'delivered' | 'read' | 'failed';

interface MessageButton {
  id: string;
  title: string;
  action?: string;
}

interface SendMessageOptions {
  sessionId: string;    // required; must not contain ":"
  visitorName?: string;
  messageType?: 'TEXT' | 'media';
  mediaUrl?: string;    // required when messageType is 'media'
  mediaType?: 'audio' | 'image' | 'video' | 'document';
  socialMessageId?: string | null; // auto-generated when omitted
}

interface SendMessageStatusOptions {
  sessionId: string;
  socialMessageId: string;
  messageType: 'READ_UPDATE' | 'DELIVERY_UPDATE' | 'STATUS_UPDATE';
  status: 'READ' | 'DELIVERED' | 'SENT' | 'FAILED';
  visitorName?: string;
}

interface UploadMediaOptions {
  sessionId: string;
  mediaType: 'image' | 'audio' | 'document';
  visitorName?: string;
  requestId?: string;
  onProgress?: (percent: number) => void;
}

interface GetConversationOptions {
  page?: number;
  limit?: number;
}

interface SimplifiedMessage {
  _id: string;
  senderType: 'CONTACT' | 'AGENT';
  messageType: string;
  textMessage?: string;
  mediaType?: string;
  mediaUrl?: string;
  thumbnail?: string;
  status?: string;
  socialMessageId?: string | null;
  seq?: number;
  buttons?: MessageButton[];
  metadata?: Record<string, unknown>;
  createdAt?: string;
  updatedAt?: string;
}

interface MessageStatusPayload {
  socialMessageId: string;
  status: MessageDeliveryStatus;
  messageType?: 'READ_UPDATE' | 'DELIVERY_UPDATE' | 'STATUS_UPDATE';
  sessionId?: string;
  timestamp?: string;
}

interface Pagination {
  currentPage: number;
  limit: number;
  totalMessages: number;
  totalPages: number;
  hasNextPage: boolean;
  hasPrevPage: boolean;
  nextPage: number | null;
  prevPage: number | null;
}

interface GetConversationResponse {
  messages: SimplifiedMessage[];
  pagination: Pagination;
}

interface ChannelInfoResponse {
  id: number;
  name: string;
  channelUid: string;
  channelType: string;
  channelConfig: Record<string, unknown>;
}

Events

The client extends EventEmitter. Subscribe with client.on(eventName, handler). Attach listeners before calling connect().

  • connection_ready – first successful Socket.IO join (or REST-only ready). No payload.
  • connection_error – connect or join failed (Error).
  • reconnecting / reconnected – transport reconnect and room re-join (no payload).
  • error – connection or request failures (Error).
  • message – SimplifiedMessage when an agent/content message arrives for this session.
  • message_media_ready – SimplifiedMessage when background media finalize completes; patch the bubble.
  • message_status – MessageStatusPayload for delivery/read ticks on messages you sent.

Authentication & security

All requests use the channel secret in the X-AWR-Channel-Secret header (or Authorization: Bearer <secret>). Get the connection key and secret when creating the Custom Channel in the AWR Connect webapp; the secret is shown only once and must be stored securely.

Server-side: the API compares the secret using a timing-safe comparison to avoid leaking information. Media upload is rate-limited (e.g. 30 requests per minute per IP). Uploaded document filenames use an allowlisted extension from the validated MIME type, not the client filename.

Live example

Enter your Custom Channel id (Channel ID) and secret, then click Open chat to use the SDK in a real-time chat.

Use the form below to try the SDK (or the same REST calls if the SDK is not loaded). Fill in your API base URL, channel ID (id), secret, and optionally session ID and visitor name. In the chat you can send text, or use Attach to upload an image, audio, or document via S3 upload-intents, then send as a media message.
